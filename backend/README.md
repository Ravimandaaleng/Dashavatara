# Dashavatara Backend

Backend API for Dashavatara.

Dashavatara is an AI-powered home service marketplace that connects customers with verified technicians and contractors.

## Current Phase

Phase B1 - Backend Foundation

## Technology

- Node.js
- Express.js
- MongoDB / Mongoose
- REST API
- dotenv
- CORS
- Cookie Parser

## Run Development Server

```bash
npm install
npm run dev
